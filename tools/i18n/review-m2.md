# M2 slice translation review

Scope: every key in `client/src/i18n/en.json` (3,419 keys), read against `tools/i18n/source.id.json` and
`tools/i18n/glossary.json`. Tutorial chains 90000-94015 and the first main quests (10xxx-18xxx), the
explore and Leveling guide quests (5xxxx), scenes and exploration zones 21xx-25xx, NPC lines, buffs,
outfit names, skills, and the items they give. Identical sources were compared across the five
villages, then checked by script for placeholder and tag counts, numbers, glossary names, leftover
Indonesian, stray tags, spacing and a/an errors. Of the 3,419 keys, 747 had earlier hand-reviewed values;
those were read again too.

All fixes live in `overrides.json` (merge precedence). 78 keys changed.
